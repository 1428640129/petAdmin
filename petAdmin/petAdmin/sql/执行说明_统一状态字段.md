# 统一状态字段执行说明

## 脚本说明

`modify_status_fields_to_number.sql` 脚本会将以下字段从字符串类型改为数字类型：

1. **订单状态** (`pet_bath_order.status`)
   - `unpaid` → `0` (待支付)
   - `paid` → `1` (已支付)
   - `in_service` → `2` (服务中)
   - `completed` → `3` (已完成)
   - `refunded` → `4` (已退款)
   - `cancelled` → `5` (已取消)

2. **预约状态** (`pet_bath_appointment.status`)
   - `pending` → `0` (待确认)
   - `confirmed` → `1` (已确认)
   - `in_service` → `2` (服务中)
   - `completed` → `3` (已完成)
   - `cancelled` → `4` (已取消)

3. **支付方式** (`pet_bath_payment.payment_type`)
   - `alipay` → `0` (支付宝)
   - `wechat` → `1` (微信)
   - `balance` → `2` (余额)

4. **支付状态** (`pet_bath_payment.status`)
   - `pending` → `0` (待支付)
   - `paid` → `1` (已支付)
   - `failed` → `2` (支付失败)
   - `refunded` → `3` (已退款)

5. **通知类型** (`pet_bath_notification.notification_type`)
   - `appointment_created` → `0` (预约创建)
   - `appointment_confirmed` → `1` (预约确认)
   - `service_started` → `2` (服务开始)
   - `service_completed` → `3` (服务完成)
   - `order_paid` → `4` (订单支付)
   - `order_cancelled` → `5` (订单取消)

## 执行步骤

### 1. 备份数据库（重要！）
```sql
-- 备份相关表
mysqldump -u用户名 -p密码 数据库名 pet_bath_order pet_bath_appointment pet_bath_payment pet_bath_notification > backup_status_fields.sql
```

### 2. 执行SQL脚本
```sql
-- 在MySQL中执行
source modify_status_fields_to_number.sql;
```

或者直接在MySQL客户端中执行脚本内容。

### 3. 验证修改结果
脚本末尾包含了验证查询，执行后检查：
- 字段类型是否已改为 `char(1)`
- 注释是否正确
- 数据是否正确转换

## 注意事项

1. **数据备份**：执行前必须备份数据库
2. **数据转换**：脚本会自动将现有字符串数据转换为数字
3. **兼容性**：如果字段已经是数字，UPDATE语句不会改变它们
4. **默认值**：所有字段默认值设为 `'0'`
