# 聊天消息功能实现说明

## 功能概述

实现了完整的聊天消息系统，支持用户与商家之间的文字、图片、视频消息交流。

## 技术选型

### 后端技术栈
- **数据库**: MySQL（已有）
- **框架**: Spring Boot + MyBatis（已有）
- **文件存储**: 本地存储（使用项目现有的文件上传功能）
- **实时通信**: HTTP轮询（简单可靠，适合中小型应用）

### 前端技术栈
- **框架**: Uni-app（Vue 3 Composition API）
- **UI组件**: uni-icons（图标）
- **文件选择**: uni.chooseImage、uni.chooseVideo（原生API）

### 技术选型说明

#### 为什么选择HTTP轮询而不是WebSocket？
1. **简单可靠**: HTTP轮询实现简单，不需要额外的WebSocket服务器
2. **兼容性好**: 所有平台都支持HTTP请求
3. **适合场景**: 对于中小型应用，轮询间隔5-10秒即可满足需求
4. **易于维护**: 不需要处理WebSocket连接断开、重连等复杂逻辑

#### 文件存储方案
- **当前**: 本地存储（使用项目现有的`/common/upload`接口）
- **未来扩展**: 可以轻松迁移到OSS（阿里云/腾讯云）存储

## 数据库设计

### 表结构：pet_bath_message

```sql
CREATE TABLE `pet_bath_message` (
  `message_id` bigint NOT NULL AUTO_INCREMENT COMMENT '消息ID',
  `sender_id` bigint NOT NULL COMMENT '发送者ID',
  `sender_type` char(1) NOT NULL DEFAULT '0' COMMENT '发送者类型（0=用户,1=商家）',
  `receiver_id` bigint NOT NULL COMMENT '接收者ID',
  `receiver_type` char(1) NOT NULL DEFAULT '1' COMMENT '接收者类型（0=用户,1=商家）',
  `message_type` char(1) NOT NULL DEFAULT '0' COMMENT '消息类型（0=文字,1=图片,2=视频）',
  `content` text COMMENT '消息内容',
  `file_url` varchar(500) DEFAULT NULL COMMENT '文件URL',
  `file_size` bigint DEFAULT NULL COMMENT '文件大小（字节）',
  `file_duration` int DEFAULT NULL COMMENT '视频时长（秒）',
  `thumbnail_url` varchar(500) DEFAULT NULL COMMENT '缩略图URL',
  `is_read` char(1) DEFAULT '0' COMMENT '是否已读（0=未读,1=已读）',
  `read_time` datetime DEFAULT NULL COMMENT '阅读时间',
  `create_by` varchar(64) DEFAULT '' COMMENT '创建者',
  `create_time` datetime DEFAULT NULL COMMENT '创建时间',
  `update_by` varchar(64) DEFAULT '' COMMENT '更新者',
  `update_time` datetime DEFAULT NULL COMMENT '更新时间',
  `remark` varchar(500) DEFAULT NULL COMMENT '备注',
  PRIMARY KEY (`message_id`),
  KEY `idx_sender` (`sender_id`, `sender_type`),
  KEY `idx_receiver` (`receiver_id`, `receiver_type`),
  KEY `idx_create_time` (`create_time`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='聊天消息表';
```

### 字段说明

- **sender_id/sender_type**: 发送者信息（支持用户和商家）
- **receiver_id/receiver_type**: 接收者信息
- **message_type**: 消息类型（0=文字,1=图片,2=视频）
- **content**: 文字消息内容，或文件消息的预览文本
- **file_url**: 图片/视频文件URL
- **file_size**: 文件大小（用于显示）
- **file_duration**: 视频时长（秒）
- **thumbnail_url**: 视频缩略图URL（可选，未来可扩展）

## 后端API接口

### 1. 获取聊天列表
```
GET /bath/message/chatList
参数: userId, userType
返回: 与各个用户的最后一条消息列表
```

### 2. 获取聊天记录
```
GET /bath/message/chatHistory
参数: senderId, senderType, receiverId, receiverType
返回: 两个用户之间的完整聊天记录
```

### 3. 发送消息
```
POST /bath/message
Body: {
  senderId, senderType,
  receiverId, receiverType,
  messageType,  // 0=文字,1=图片,2=视频
  content,      // 文字内容或预览文本
  fileUrl,      // 文件URL（图片/视频）
  fileSize,     // 文件大小（可选）
  fileDuration  // 视频时长（可选）
}
```

### 4. 标记消息为已读
```
POST /bath/message/markChatRead
参数: senderId, senderType, receiverId, receiverType
```

### 5. 查询未读消息数量
```
GET /bath/message/unreadCount
参数: receiverId, receiverType
返回: 未读消息数量
```

### 6. 文件上传（复用现有接口）
```
POST /common/upload
文件: file (MultipartFile)
返回: { url, fileName, ... }
```

## 前端页面

### 1. 消息列表页 (`pages/message/message.vue`)
- 显示与各个用户的最后一条消息
- 显示未读消息红点
- 点击进入聊天详情页
- 下拉刷新

### 2. 聊天详情页 (`pages/chat/chat.vue`)
- 显示完整的聊天记录
- 支持发送文字、图片、视频
- 消息气泡样式（左：对方，右：自己）
- 图片预览、视频播放
- 自动滚动到底部
- 进入页面时自动标记为已读

## 使用流程

### 用户端
1. 进入"消息"页面，查看聊天列表
2. 点击某个聊天，进入聊天详情页
3. 可以发送文字、图片、视频消息
4. 查看对方发送的消息

### 商家端
1. 同样可以查看聊天列表
2. 与用户进行聊天
3. 回复用户的消息

## 文件上传流程

### 图片上传
1. 用户选择图片（相册/拍照）
2. 前端调用`uni.chooseImage`
3. 上传到`/common/upload`接口
4. 获取文件URL
5. 发送消息（messageType=1, fileUrl=URL）

### 视频上传
1. 用户选择视频（相册/拍摄）
2. 前端调用`uni.chooseVideo`
3. 上传到`/common/upload`接口
4. 获取文件URL和时长
5. 发送消息（messageType=2, fileUrl=URL, fileDuration=时长）

## 性能优化建议

### 1. 图片压缩
前端上传前可以压缩图片：
```javascript
// 使用uni.compressImage压缩图片
uni.compressImage({
  src: filePath,
  quality: 80,  // 压缩质量
  success: (res) => {
    // 上传压缩后的图片
  }
});
```

### 2. 分页加载
聊天记录可以分页加载，避免一次性加载过多消息：
- 首次加载最近50条
- 上拉加载更多历史消息

### 3. 消息缓存
前端可以缓存聊天记录，减少API调用：
- 使用`uni.setStorageSync`缓存消息列表
- 定时刷新（如每10秒）

### 4. 视频缩略图
视频消息可以生成缩略图：
- 后端处理：使用FFmpeg生成缩略图
- 前端显示：优先显示缩略图，点击播放视频

## 未来扩展

### 1. 实时推送（WebSocket）
如果需要实时推送，可以集成WebSocket：
- 使用Spring WebSocket
- 前端使用uni.connectSocket
- 消息到达时实时推送

### 2. 消息状态
可以添加更多消息状态：
- 发送中
- 已送达
- 已读

### 3. 语音消息
可以添加语音消息支持：
- 使用`uni.recordManager`录音
- 上传音频文件
- 播放音频

### 4. 文件存储迁移到OSS
迁移到云存储（阿里云OSS/腾讯云COS）：
- 修改上传接口
- 配置OSS客户端
- 前端直接上传到OSS（使用STS临时凭证）

## 注意事项

1. **文件大小限制**: 建议限制图片和视频大小（如图片<5MB，视频<50MB）
2. **文件类型验证**: 后端需要验证文件类型，防止上传恶意文件
3. **权限控制**: 确保用户只能查看和发送自己的消息
4. **数据清理**: 定期清理过期的聊天记录（如6个月前的）
5. **消息加密**: 敏感信息可以考虑加密存储

## API调用示例

### 发送文字消息
```javascript
uni.request({
  url: 'http://your-domain/bath/message',
  method: 'POST',
  data: {
    senderId: 1,
    senderType: '0',
    receiverId: 2,
    receiverType: '1',
    messageType: '0',
    content: '你好，我想预约宠物洗澡服务'
  },
  header: {
    'Authorization': 'Bearer token',
    'Content-Type': 'application/json'
  }
});
```

### 发送图片消息
```javascript
// 1. 上传图片
uni.uploadFile({
  url: 'http://your-domain/common/upload',
  filePath: imagePath,
  name: 'file',
  success: (res) => {
    const result = JSON.parse(res.data);
    // 2. 发送消息
    uni.request({
      url: 'http://your-domain/bath/message',
      method: 'POST',
      data: {
        senderId: 1,
        senderType: '0',
        receiverId: 2,
        receiverType: '1',
        messageType: '1',
        content: '[图片]',
        fileUrl: result.data.url
      }
    });
  }
});
```
