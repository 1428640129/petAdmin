# 新增服务长毛短毛价格设置功能说明

## 功能概述

管理员在新增洗浴服务时，可以为长毛和短毛分别设置价格梯度。

## 已完成的修改

### 1. 前端表单更新
**文件**: `pet/src/views/bath/service/modules/service-operate-drawer.vue`

**修改内容**:
- ✅ 价格梯度数据结构添加 `petType` 字段
- ✅ 默认价格梯度设置为短毛（`petType: '0'`）
- ✅ 表单中分别显示"短毛价格梯度"和"长毛价格梯度"
- ✅ 添加"添加长毛价格梯度"按钮（如果还没有长毛价格）
- ✅ 服务类型选择改为使用数字（`0=基础洗浴,1=深度护理,2=豪华套餐`）
- ✅ 提交时确保所有价格梯度都有 `petType` 字段

### 2. 数据结构

**价格梯度对象**:
```typescript
{
  petType: string;    // '0'=短毛, '1'=长毛
  weightMin: number;  // 最小体重
  weightMax: number;  // 最大体重
  price: number;      // 价格
}
```

### 3. 默认价格梯度

**短毛价格梯度**（默认添加）:
- 0-5kg
- 5.01-15kg
- 15.01-30kg
- 30.01-999kg

**长毛价格梯度**（可选添加）:
- 点击"添加长毛价格梯度"按钮后添加
- 同样包含4个体重区间

## 使用流程

### 新增服务时

1. **填写基本信息**
   - 服务名称
   - 服务类型（基础洗浴/深度护理/豪华套餐）
   - 服务描述
   - 服务时长
   - 状态、排序等

2. **设置短毛价格梯度**
   - 系统默认显示4个体重区间的价格输入框
   - 管理员填写每个区间的价格

3. **添加长毛价格梯度**（可选）
   - 如果服务适用于长毛宠物，点击"添加长毛价格梯度"按钮
   - 系统会添加4个长毛价格梯度输入框
   - 管理员填写每个区间的价格

4. **提交保存**
   - 系统会将所有价格梯度（包括petType）一起提交
   - 后端会为每个价格梯度设置对应的 `petType` 值

## 数据提交格式

提交到后端的数据格式：
```json
{
  "serviceName": "基础洗浴",
  "serviceType": "0",
  "serviceDesc": "包含洗澡、吹干、基础护理",
  "duration": 60,
  "status": "0",
  "sortOrder": 1,
  "prices": [
    {
      "petType": "0",
      "weightMin": 0,
      "weightMax": 5,
      "price": 50
    },
    {
      "petType": "0",
      "weightMin": 5.01,
      "weightMax": 15,
      "price": 80
    },
    {
      "petType": "1",
      "weightMin": 0,
      "weightMax": 5,
      "price": 60
    },
    {
      "petType": "1",
      "weightMin": 5.01,
      "weightMax": 15,
      "price": 95
    }
  ]
}
```

## 后端处理

后端 `PetBathServiceServiceImpl.insertBathService()` 方法会：
1. 保存服务基本信息
2. 遍历 `prices` 列表
3. 为每个价格梯度设置 `serviceId`
4. 保存价格梯度（包含 `petType` 字段）

## UI展示效果

- **短毛价格梯度**：显示在表单上方，标题为"短毛价格梯度"
- **长毛价格梯度**：显示在表单下方，标题为"长毛价格梯度"
- **添加按钮**：如果还没有长毛价格梯度，显示"添加长毛价格梯度"按钮

## 注意事项

1. **默认值**：新增服务时，默认只有短毛价格梯度
2. **可选添加**：长毛价格梯度是可选的，如果服务不适用于长毛，可以不添加
3. **数据兼容**：编辑已有服务时，如果价格梯度没有 `petType` 字段，会自动设置为 `'0'`（短毛）
4. **提交验证**：提交时会确保所有价格梯度都有 `petType` 字段
