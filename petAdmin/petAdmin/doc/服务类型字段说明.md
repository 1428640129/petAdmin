# 服务类型字段说明

## 当前状态

`pet_bath_service` 表中的 `service_type` 字段：
- **字段类型**: `varchar(50)`
- **字段注释**: `服务类型（如：基础洗浴、深度护理等）`
- **当前数据**: `基础服务`、`深度服务`、`豪华服务` 等字符串值

## 是否需要统一为数字？

### 建议：保持字符串类型

**原因**：
1. **业务数据特性**：服务类型是业务数据，不是状态枚举
2. **扩展性强**：未来可能增加更多服务类型（如：SPA护理、美容造型、医疗护理等）
3. **可读性好**：字符串值更直观，便于理解和维护
4. **灵活性高**：不需要修改代码就能添加新的服务类型

### 如果确实需要统一为数字

如果项目中其他类似字段都使用数字，为了保持一致性，可以考虑改为数字：

**映射方案**：
- `0` = 基础洗浴
- `1` = 深度护理
- `2` = 豪华套餐
- `3` = 其他（可扩展）

**实施步骤**：
1. 修改字段类型为 `char(1)`
2. 更新现有数据
3. 创建常量类 `ServiceTypeConstants`
4. 更新Java代码和前端代码
