## 状态映射关系

### 预约状态
- `'0'` = 待确认（pending）
- `'1'` = 已确认（confirmed）
- `'2'` = 服务中（in_service）
- `'3'` = 已完成（completed）
- `'4'` = 已取消（cancelled）

### 订单状态
- `'0'` = 待支付（unpaid）
- `'1'` = 已支付（paid）
- `'2'` = 服务中（in_service）
- `'3'` = 已完成（completed）
- `'4'` = 已退款（refunded）
- `'5'` = 已取消（cancelled）

### 支付方式
- `'0'` = 支付宝（alipay）
- `'1'` = 微信（wechat）
- `'2'` = 余额（balance）

### 支付状态
- `'0'` = 待支付（pending）
- `'1'` = 已支付（paid）
- `'2'` = 支付失败（failed）
- `'3'` = 已退款（refunded）

## 使用示例

### 在Vue组件中使用

```javascript
import { APPOINTMENT_STATUS, APPOINTMENT_STATUS_TEXT } from '@/utils/constants.js'

export default {
  data() {
    return {
      appointment: {
        status: APPOINTMENT_STATUS.PENDING  // '0'
      }
    }
  },
  methods: {
    checkStatus() {
      // 判断状态
      if (this.appointment.status === APPOINTMENT_STATUS.PENDING) {
        // 待确认状态的处理
      }
      
      // 获取状态文本
      const statusText = APPOINTMENT_STATUS_TEXT[this.appointment.status]
    }
  }
}
```

### 在模板中使用

```vue
<template>
  <!-- 状态判断 -->
  <button v-if="appointment.status === APPOINTMENT_STATUS.PENDING">
    确认预约
  </button>
  
  <!-- 状态显示 -->
  <text>{{ APPOINTMENT_STATUS_TEXT[appointment.status] }}</text>
  
  <!-- CSS类名 -->
  <view :class="'status-' + appointment.status">
    状态标签
  </view>
</template>
```

## 注意事项

1. **导入常量**：使用状态前必须先导入常量
2. **字符串比较**：状态值是字符串类型（`'0'`, `'1'`），比较时注意类型
3. **CSS类名**：使用 `status-0`, `status-1` 等格式，而不是 `pending`, `confirmed`
4. **向后兼容**：如果后端返回的是旧格式字符串，需要在前端做转换
