## 使用方式

### Java代码中使用
```java
import com.pet.common.constants.ServiceTypeConstants;

// 使用常量
service.setServiceType(ServiceTypeConstants.BASIC);  // "0"
service.setServiceType(ServiceTypeConstants.DEEP_CARE);  // "1"
service.setServiceType(ServiceTypeConstants.LUXURY);  // "2"

// 判断类型
if (ServiceTypeConstants.BASIC.equals(service.getServiceType())) {
    // 基础洗浴
}
```

### 前端代码中使用
```javascript
import { SERVICE_TYPE, SERVICE_TYPE_TEXT } from '@/utils/constants.js'

// 使用常量
const serviceType = SERVICE_TYPE.BASIC  // '0'

// 获取文本
const text = SERVICE_TYPE_TEXT[serviceType]  // '基础洗浴'
```

## 注意事项

1. **数据迁移**：执行SQL脚本后，现有数据会自动转换

3. **扩展性**：如果需要添加新的服务类型，可以扩展为 `'3'`, `'4'` 等
